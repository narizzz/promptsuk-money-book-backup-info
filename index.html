Private desktop utility

PromptSuk Money Book Backup

Encrypted backups for the owner's locally operated PromptSuk Money Book.

Purpose

This utility is being configured for the PromptSuk owner's own use. It is intended to create encrypted recovery archives on the owner's Windows computer, upload them to the owner's selected private Google Drive folder, and download the uploaded copies to check their size and cryptographic checksum.

This public website contains documentation only. It does not run the Money Book application, accept payments, provide a public accounting service, or display accounting records or backup files. Setup and operational verification are still in progress.

Why Google Drive access is requested

The desktop utility requests only the drive.file permission: access to specific files or folders selected for use with the utility and files it creates. It does not request access to every file in the owner's Google Drive.

Access is used to check the selected backup folder's ownership and sharing metadata, create backup folders, upload encrypted archives and integrity manifests, and retrieve those files for verification. Google authorization happens through Google's consent screen, not through this website.

Owner control

The backup program runs on the owner's computer, not on this website and not through an AI service. The owner can stop local scheduled backups and revoke the utility's Google authorization. The computer must be running with the required account and network access; a schedule alone does not guarantee successful recovery or a fixed recovery time.
