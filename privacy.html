PromptSuk Money Book Backup

Privacy policy

Effective 19 October 2026. This policy covers the owner's private desktop backup utility and this documentation website.

Data accessed and purpose

The utility requests Google's drive.file permission, limited to items selected for use with the utility and files it creates. It uses folder and file identifiers, names, ownership and permission metadata, file sizes, and the content of its backup files to select a private destination, upload backups, and verify downloaded copies.

Encrypted recovery archives are prepared from the owner's authorized local Money Book backup process. Supporting integrity manifests describe the recovery set. The utility is not intended to read unrelated Drive documents, Gmail, contacts, Master accounting workbooks, or bank statements.

Storage and protection

The approved configuration stores recovery archives encrypted on the owner's computer and in the selected private Google Drive folder, together with integrity manifests. The archive decryption key stays on the owner's computer and is not uploaded with backups. Google access and refresh credentials are to be protected by Windows encryption tied to the owner's account, with restricted local file permissions.

The utility is still being configured. Credential storage, unattended operation, and remote verification must pass operational checks before daily use is enabled. This policy does not claim those checks have already passed.

Use and sharing

Google user data is used only to provide and verify this owner-controlled backup function. It is not sold, used for advertising or profiling, or used to train AI models. The scheduled backup program does not send backup contents or Google credentials to an AI service.

Google processes files and authorization information as the Drive and OAuth service provider. Backup files and keys are not published on this website or its public source repository. No additional users are granted access by the utility.

PromptSuk Money Book Backup's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation, and deletion

Existing backup sets are retained unless the owner separately chooses to remove them. The utility does not automatically delete older backups. The owner can stop the local scheduled task and revoke access in Google Account connections.

Revoking authorization stops future authorized access but does not delete previously stored backups. The owner controls those copies on the local computer and in Google Drive. For assistance with stopping the utility, removing its locally stored credentials, or managing backup retention, contact the maintainer below.

This documentation website

This site has no login, upload form, analytics script, or tracking code added by the maintainer. GitHub Pages hosts the static documentation and may collect technical access information, including visitor IP addresses, for security under the GitHub Privacy Statement. Do not send passwords, tokens, accounting records, or backup keys by email.

Contact and changes

Maintainer: PromptSuk owner, naris.pk@gmail.com. Material changes to the utility's data practices will be reflected here with an updated effective date before those practices are used.
